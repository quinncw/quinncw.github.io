Vim: A Short Tutorial

Introduction

HTML can be hard to understand at first. And when you get into Vim, it can feel even harder.

So, I've made a webpage that will quickly explain how to use and navigate Vim.

How do I even open/close Vim?

Opening something you can't even close is pretty annoying, and you'll probably end up giving up and closing the terminal entirely. It's even worse if you can't open it to begin with, since it is a requirement for this course!

First, let's start with the most basic basics- opening Vim. Simply cd to the directory the file you want to vim is in, and in the terminal, enter vim index.html (your file should be named index.html if you followed instructions unless he changed them).

If you aren't seeing the code you expected or it displays [New file] when trying to access an existing one, make sure you are in the right directory and/or didn't misspell the file name when entering Vim.

Make sure you remember these steps:

  1. cd to the directory your file is in.
  2. enter vim filename.html.

Now, let's get into closing Vim. There are two main commands you'll use for exiting Vim, which are :q and :wq. Whenever you want to save changes, make sure you use :wq and not :q. :q will not save any changes and you'll lose any progress you just made.

To close Vim, hit escape to make sure you're in the right mode in Vim, and type :wq (or :q if you don't want to save changes).

Remember these steps too:

  1. Hit escape to make sure you're in the right mode.
  2. Enter :wq.

How do I move in Vim??

There are many ways you can move through text in Vim. The most simple way, but one of the longest, is using arrow keys. This is mostly used for moving around in insert mode or any other situation where h, j, k and l will not work. Speaking of h, j, k and l, those 4 letters are also used to move around in terminal. This is what you'll be taught, and what you should use for the sake of habit when Vim allows. H is used to move left one character, J is used to move down one line, K is used to move up one line, and L will move you right one character. Also, with h, j, k and l, if you add a number infront (ex. 5j) you'll move in that direction and that number of lines or characters.

While there are many more ways to move around in Vim, the three other ways you'll mainly need to know how to move around are w, e and b. Their uppercase versions are a bit different, as they define words differently. For now, just use lowercase. w will move you to the beginning of the next word, e will move you to the end of the next word, and b will move you to the start of the previous word. Again, make sure you're in the right mode by pressing escape before using non-arrow key movement commands.

This is pretty important, so make sure you remember what these all do:

  • h
  • j
  • k
  • l
  • w
  • b
  • e

What else should I know when using Vim?

Vim is a great tool, with many other cool features! Unfortunately, right now, I don't have time to list all of the shortcuts and other features, so for now, I'll just name my favorite ones and the most basic ones.

Escape key
As discussed before, this allows you to return to normal mode.

I key
Second most important one. This puts you in insert mode.

V key
V puts you in visual mode
O key
O inserts a new line above the selected line. Lowercase o inserts a line below.
