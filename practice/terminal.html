How do I even open/close Vim?

Opening something you can't even close is pretty annoying, and you'll probably end up giving up and closing the terminal entirely. It's even worse if you can't open it to begin with, since it is a requirement for this course!

First, let's start with the most basic basics- opening Vim. Simply cd to the directory the file you want to vim is in, and in the terminal, enter "vim index.html" (your file should be named index.html if you followed instructions unless he changed them).

If you aren't seeing the code you expected or it says you created a new file when trying to access an existing one, make sure you are in the right directory and/or didn't misspell the file name when entering Vim.

Now, let's get into closing Vim. There are two main commands you'll use for exiting Vim, which are :q and :wq. Whenever you want to save changes, make sure you use :wq and not :q. :q will not save any changes and you'll lose any progress you just made.

To close Vim, hit escape to make sure you're in the right mode in Vim, and type ":wq: (or q if you don't want to save changes.
